# Vídeos

O site procura estes arquivos. Enquanto um arquivo não existe, aparece um quadro tracejado no lugar.

| Arquivo | Onde aparece |
|---|---|
| `hero-hook.mp4` | Hero: gancho do Longform 1, mudo, em loop |
| `l1-after.mp4` | Longform 1: player principal (vídeo editado) |
| `l1-before-60s.mp4` | Longform 1: slider, primeiros 60 s do bruto |
| `l1-after-60s.mp4` | Longform 1: slider, primeiros 60 s editados |
| `l2-after.mp4`, `l2-before-60s.mp4`, `l2-after-60s.mp4` | Longform 2 |
| `l3-after.mp4`, `l3-before-60s.mp4`, `l3-after-60s.mp4` | Longform 3 |
| `short-1.mp4`, `short-2.mp4`, `short-3.mp4` | Aba Shorts (verticais 9:16) |

Os dois arquivos de 60 s de cada longform devem começar no mesmo ponto da fala,
para o antes e o depois ficarem alinhados no slider.
